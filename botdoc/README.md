# Gerador de Comprovantes • @nyckzao

Automação para preenchimento simultâneo de:
1. **Comprovante de Conta Nubank** (comprovante de conta ativa bancária)
2. **Comprovante Energisa** (DANF3E / conta de luz de concessionária)

---

## ⚡ Como Usar

1. Dê dois cliques em [**`iniciar.bat`**](file:///c:/Users/nyckzao/Downloads/botdoc/iniciar.bat) (ou rode `python app.py`);
2. Digite o **Nome**, **CPF** e **Endereço** uma única vez;
3. Clique em **Gerar os 2 Comprovantes**;
4. Na tela de prévia, alterne entre as abas:
   - `[ 🟣 Nubank (Conta) ]`
   - `[ ⚡ Energisa (Luz) ]`
5. Baixe individualmente (**Baixar Nubank**, **Baixar Energisa**) ou baixe os dois juntos no botão verde **📦 Baixar os 2 (ZIP)**.
